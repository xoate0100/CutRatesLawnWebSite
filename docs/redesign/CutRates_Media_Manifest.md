## Wiring into the media-slot pipeline
1. Download each licensed file from its Envato link (register to the project).
2. Drop into the site's media pipeline; reference by slot name, not filename.
3. Apply the slot's treatment class from the v2 system (`t-duotone`, `t-grain`, `t-mask`, `t-stripe`, scrim) so every asset lands on-brand automatically.
4. Keep this manifest as the source of truth — one place to see every asset, its slot, and its license.

*Searches used are in the v2 slot map, so this kit is re-pullable and expandable (e.g., per-service or per-town photography) any time.*
