# Decision Proposals

Add new architectural decisions here as YAML files. Do **not** edit `5_reference_architectures/DECISION_REGISTRY.yaml` directly.

## Proposal file format

```yaml
decision_id: DEC-XXXX-SHORT-NAME
status: proposed
decision_basis: >
  Why this decision is needed.
resurrection_trigger_keywords: []
reopen_requires: N/A for new decisions
```

After human review, merge into the locked registry.
